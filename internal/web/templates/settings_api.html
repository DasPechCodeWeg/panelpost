Examples

Run a report and deliver it:

curl -X POST -H "Authorization: Bearer pp_…" https://panelpost.example.com/api/v1/reports/REPORT_ID/run

Render any dashboard to PDF on demand:

curl -X POST -H "Authorization: Bearer pp_…" -H "Content-Type: application/json" \
  -d '{"connection_id":"…","dashboard_uid":"…","time":{"preset":"previous_month"}}' \
  -o report.pdf https://panelpost.example.com/api/v1/render
